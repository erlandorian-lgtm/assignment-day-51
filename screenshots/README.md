# Screenshots

After running the project, save these screenshots in this folder:

1. `producer.png` — producer terminal showing successful delivery to the `transactions` topic.
2. `streaming_console.png` — Spark console showing the running total and at least one non-empty 1-minute window result.
3. Optional: `valid_topic.png` and `dlq_topic.png` — sample records consumed from the output topics.

These screenshots must be captured from the actual local run; they are not generated placeholders.
